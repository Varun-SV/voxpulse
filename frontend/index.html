OpenAI Drop-In API Gateway

Connect Open WebUI, LibreChat, Obsidian, Home Assistant, or your Python scripts directly.

Python (Official OpenAI SDK) cURL Node.js / JS 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed"
)

response = client.audio.speech.create(
    model="voxpulse-kokoro",  # or "tts-1", "voxpulse-piper", "voxpulse-f5"
    voice="alloy",            # maps to local af_heart
    input="Hello from self-hosted VoxPulse Studio!"
)

response.stream_to_file("output.mp3")

Open WebUI Integration

Go to Settings → Audio → Text-to-Speech (TTS):

  • TTS Engine: OpenAI
  • API Base URL: http://host.docker.internal:8000/v1
  • API Key: voxpulse
  • Voice: alloy or af_heart

LibreChat Integration

Add to your librechat.yaml:

tts:
  openai:
    url: "http://localhost:8000/v1/audio/speech"
    apiKey: "dummy-key"
    model: "tts-1"
    voice: "alloy"
