Ultra-Fast CPU Synthesis

Powered by Kokoro-82M and Piper ONNX runtimes. Generates natural speech in under 80ms on standard CPUs without requiring an expensive NVIDIA GPU.

Deployment

Launch in Under 30 Seconds

Get your own private speech engine running with standard Docker commands.

1

Clone the Repository

Grab the project files and configuration.

git clone https://github.com/Varun-SV/voxpulse.git
cd voxpulse
2

Start the Container

Launches the core engines and web studio.

docker compose up -d
3

Open Studio & Connect APIs

Access the studio interface or plug into your AI apps.

# Web Studio UI
http://localhost:8000

# OpenAI API Endpoint
http://localhost:8000/v1/audio/speech
